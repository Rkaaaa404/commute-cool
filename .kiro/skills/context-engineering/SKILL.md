# Context Engineering

## Overview
Context Engineering is the discipline of structuring and curating the information provided to the AI agent. This skill guides the agent in balancing its token budget, planning complex multi-step workflows, and building a structured mental model of the codebase.

## When to Use
- When planning the architecture of a new feature.
- When managing a large-scale project with many interdependent tasks.
- When trying to optimize agent-user communication channels.

## Instructions
1. Outline a clear implementation plan before writing any code.
2. Use progressive disclosure to load metadata first, then detailed content on demand.
3. Maintain a structured log of active/completed/pending tasks.
