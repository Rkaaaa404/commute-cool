# Planning and Task Breakdown

## Overview
This skill organizes large, ambiguous project goals into step-by-step development lists. It helps track dependency structures, avoid missing requirements, and maintain focus on critical milestones.

## When to Use
- At the start of a new feature implementation or when modifying core backend modules.
- When organizing tasks to meet complex non-functional requirements (performance, reliability).

## Instructions
1. List all functional requirements impacted by the task.
2. Order steps logically, putting data collection and pipeline setup before downstream consumer code.
3. Specify verification steps for each completed subtask.
