# Idea Refinement

## Overview
This skill enhances system concepts, validates architectural choices, and refines ideas based on feedback and constraints. It helps optimize features like target metrics, case studies, and validation models.

## When to Use
- When modifying specifications or proposing new modules.
- When aligning system designs with local parameters (e.g., Surabaya case study constraints).
- When detailing validation methods (e.g., comparing shadows against sat imagery).

## Instructions
1. Review the input idea against constraints listed in project documents (e.g., requirement.md).
2. Propose concrete improvements, including specific APIs, metrics, or validation plans.
3. Format feedback constructively, prioritizing feasible integrations.
